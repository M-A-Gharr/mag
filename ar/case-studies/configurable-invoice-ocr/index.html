معالجة المستندات · OpenView

استخراج بيانات الفواتير مع مراجعتها وتعديلها داخل التطبيق

طوّرت لدى OpenView تطبيقًا للتعرّف الضوئي على النصوص في فواتير JPG وPDF. كان المستخدم يختار الحقول المطلوبة أو يطلب استخراجًا أوسع، ثم يراجع النتائج ويعدّلها ويعتمدها داخل التطبيق.

مناقشة مشروع مشابه

الملف التقني للمشروع

التقنيات المستخدمة

Python, Tesseract, TensorFlow, Rossum AI

البنية ومسارات العمل

تطبيق لاستخراج فواتير JPG / PDF مع تحديد الحقول وخطوات المراجعة والتعديل والاعتماد.

التكامل والبيانات

Tesseract وTensorFlow وRossum AI لمعالجة المستندات ومخرجات منظّمة بصيغتي JSON وCSV.

دوري ومسؤولياتي

تطوير الاستخراج القابل للتخصيص ومسار مراجعة النتائج داخل التطبيق لدى OpenView.

التحدي

تختلف المعلومات الواردة في الفواتير، وقد يحتاج المستخدم إلى حقول معيّنة، مثل رقم الفاتورة، أو إلى استخراج مجموعة أوسع من البيانات.

ما طوّرته

طوّرت التطبيق باستخدام Python وTesseract وTensorFlow وRossum AI. كان المستخدم يحدّد الحقول المطلوبة أو يطلب استخراجًا أوسع، ثم يراجع القيم ويعدّلها داخل التطبيق ويعتمد النتيجة قبل استلام البيانات المنظّمة بصيغة JSON أو CSV.

استخراج قابل للتخصيص لبيانات الفواتير، مع تعديل النتائج واعتمادها داخل التطبيق قبل إخراجها بصيغة JSON أو CSV.
