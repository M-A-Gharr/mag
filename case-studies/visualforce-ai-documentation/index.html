The delivered solution

An open-source command-line tool for Salesforce teams. It reads Visualforce pages and their Apex classes, then writes clear Markdown documentation with an AI summary of what each page does. Documenting legacy pages becomes a one-command job.

Implemented features

  • Reads Visualforce pages: forms, fields, buttons and page blocks
  • Finds the controllers, extensions and Apex methods behind each page
  • AI summary of what each component is for
  • Structured Markdown output: overview, components, controllers
  • Editable Handlebars templates
  • Runs from the command line, source code on GitHub
