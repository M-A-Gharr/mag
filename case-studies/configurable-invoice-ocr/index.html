Invoice extraction with in-app review and editing

At OpenView, I built an invoice OCR application for JPG and PDF documents. Users could choose the fields to capture or request broader extraction, then review, edit and validate the result directly in the application.

The challenge

Invoices contain different information, and users may need particular fields, such as an invoice ID, or broader extraction.

What I built

I built the application using Python, Tesseract, TensorFlow and Rossum AI. Users could configure the fields they wanted extracted or request broader extraction. They could then review the values, edit them directly in the application and validate the result before receiving structured JSON or CSV output.
