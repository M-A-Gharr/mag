La solution livrée

Un outil open source en ligne de commande pour les équipes Salesforce. Il lit les pages Visualforce et leurs classes Apex, puis rédige une documentation Markdown claire, avec un résumé par IA du rôle de chaque page. Documenter d'anciennes pages tient en une seule commande.

Fonctionnalités réalisées

  • Lecture des pages Visualforce : formulaires, champs, boutons et blocs
  • Repérage des contrôleurs, extensions et méthodes Apex derrière chaque page
  • Résumé par IA du rôle de chaque composant
  • Documentation Markdown structurée : vue d'ensemble, composants, contrôleurs
  • Modèles Handlebars modifiables
  • Utilisation en ligne de commande, code source sur GitHub
