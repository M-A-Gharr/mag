Expertise

Développement d'applications web sur mesure

Je conçois des applications web qui épousent la façon dont votre équipe travaille vraiment : outils internes, CRM, portails clients, plateformes de prospection. Aujourd'hui, je les construis chez SIMTIS, pour des équipes au Maroc et à l'export.

Parlons de votre application

Les problèmes que je résous

  • les équipes commerciales qui suivent leurs prospects dans des tableurs ou des boîtes mail ;
  • les entreprises qui ont besoin d'un outil interne que le marché ne propose pas ;
  • les groupes à plusieurs magasins ou activités, qui veulent une vue commune ;
  • les projets qui doivent fonctionner en plusieurs langues, arabe compris.

Ce que je réalise

  • applications web et plateformes métier en React, Node.js et TypeScript ;
  • CRM et outils de prospection, avec pipeline, relances et rapports ;
  • intégration à vos données et à vos outils existants : API, fichiers, ERP, services externes ;
  • automatisation des tâches répétitives de votre équipe ;
  • interfaces en français, en anglais et en arabe, de droite à gauche quand il le faut.

Ce que vous recevez

Les livrables sont définis selon la prestation choisie et validés ensemble avant le développement. La maintenance et les évolutions sont cadrées séparément.

  • Un périmètre écrit : utilisateurs, parcours, fonctionnalités prioritaires et données à connecter.
  • Une application avec les écrans métier et les permissions prévus : outil interne, CRM ou portail client.
  • Les connexions convenues aux API, fichiers ou systèmes existants, avec vérification des échanges.
  • Une version testée et déployée, un guide de prise en main et une présentation aux utilisateurs.

Le premier échange

Nous faisons le point sur votre fonctionnement actuel, les utilisateurs, les outils et les contraintes. Nous définissons ensuite la prochaine étape adaptée : cadrage, prototype ou proposition de réalisation.

Compétences techniques

Des technologies et des architectures utilisées dans mes projets, des outils internes aux plateformes commerciales connectées.

Technologies utilisées

  • React, TypeScript, Vite et TanStack Start pour les interfaces web ; React avec Three.js / WebGL pour le showroom immobilier interactif.
  • Node.js et PostgreSQL pour la gestion de boulangerie ; Supabase pour B2B Lead Intelligence.
  • PHP pour les modules PrestaShop sur mesure ; Python pour la migration de données et l’extraction de factures ; C# pour la gestion de cabinet médical et Java/JEE pour le projet bancaire.

Architectures applicatives

  • Interfaces React reliées à Node.js et à une base relationnelle, avec stocks, commandes, ventes et rapports dans une même application.
  • Applications avec authentification, permissions par rôle et circuits de validation, notamment pour les visuels générés par IA.
  • Site connecté à un CRM distinct : les demandes sont enregistrées avant envoi, puis renvoyées automatiquement lorsque le CRM est indisponible.

Intégrations et échanges de données

  • API REST et services externes : OpenAI et FASHN AI pour les fonctions IA, Hunter.io pour enrichir les contacts et Apify pour rechercher des prospects.
  • Synchronisation des stocks ERP par imports CSV planifiés ; migration WooCommerce vers PrestaShop avec imports rejouables et prévention des doublons.
  • Intégrations Salesforce avec Apex, Lightning Web Components, Flow et Node.js ; OCR de factures avec Tesseract et Rossum AI, vérification humaine et sorties JSON / CSV.

Comment je travaille

  1. Comprendre votre travail

    J'observe d'abord comment votre équipe travaille aujourd'hui, et ce qui la ralentit. L'outil suit ce travail, pas l'inverse.

  2. Un périmètre clair

    Je formalise le besoin par écrit, découpé en étapes, avec un calendrier.

  3. Des livraisons régulières

    Je développe par étapes courtes, avec une démonstration à chaque fois, pour ajuster avant qu'il ne soit trop tard.

  4. Tests, mise en ligne et formation

    L'outil est testé avant sa mise en ligne. J'écris les guides et je forme les personnes qui l'utiliseront.

  5. Suivi après livraison

    Après la livraison, je reste sur le suivi : maintenance, corrections et évolutions.
